SENURA landing page
===================
Open index.html in a browser (double-click). Files:
  index.html   structure and content
  styles.css   design (colors/fonts are CSS variables at the top)
  main.js      animations, menu, form validation, before/after sliders
  assets/hero.webp   hero photo (replace with a new photo of the same name)

Placeholders to edit: About text, services, testimonials, FAQ answers, footer email/phone.
Before/after photos: replace the slots in index.html (.ba) with <img> tags inside each <figure>.
The contact form has no backend yet (see the TODO in main.js).
